# TODO First

**오늘 할 일, 중요한 것부터.**

오늘 해야 할 일과 우선순위를 앱, 메뉴 막대, 위젯에서 빠르게 확인하는 macOS 앱입니다.

> 현재는 프로젝트 초기 설정 단계입니다. 아래 기능은 첫 버전의 개발 범위이며, 아직 구현되지 않았습니다.

## 첫 버전

- 오늘의 할 일 추가·수정·삭제
- 우선순위 설정 및 우선순위별 정렬
- 완료 체크와 오늘의 진행 현황
- 메뉴 막대에서 목록 확인 및 완료 처리
- macOS 위젯에서 중요한 할 일과 완료 현황 확인
- 앱·메뉴 막대·위젯 간 로컬 데이터 공유

## 기술 방향

- Swift / SwiftUI: macOS 네이티브 앱
- MenuBarExtra: 메뉴 막대 빠른 보기
- WidgetKit: 데스크톱 및 알림 센터 위젯
- App Groups: 앱과 위젯의 데이터 공유

## 개발 순서

1. Xcode 앱 및 위젯 타깃 구성
2. 할 일 모델과 로컬 저장 구현
3. 오늘의 목록과 우선순위 UI 구현
4. 메뉴 막대 빠른 보기 연결
5. 위젯 및 공유 데이터 연결
6. 기능·접근성·날짜 전환 동작 검증

## 개발 환경

macOS 및 Xcode를 사용합니다. Xcode 프로젝트 생성 후 실행 방법과 서명 설정을 추가할 예정입니다.
