## P에서 J로, 오늘부터

**P2J**는 MBTI의 **P → J**에서 시작했습니다. 머릿속에만 있던 계획을 적고, 우선순위를 정하고, 끝낸 일을 체크하는 작은 루틴을 만듭니다.

오늘 마무리할 일도, 매일 이어갈 습관도 한곳에. 작업 중에는 메뉴 막대에서 빠르게 확인하고, 하루의 기록은 통계로 돌아보세요.

> **개발 중인 프로젝트입니다.** 현재 소스를 빌드해 실행할 수 있으며, 설치용 배포 파일은 아직 제공하지 않습니다. 위젯의 실제 데스크톱 등록·갱신은 개발 서명 환경에서 검증할 예정입니다.

**하루의 기준은 Mac의 현지 시각 오전 6시입니다.** 새벽 0시~5시 59분에는 전날 목록과 완료 상태가 유지됩니다. 오전 6시부터 다음 작업일로 넘어가며 완료 기록은 통계에 남습니다.

## 주요 기능

| | 할 수 있는 일 |
| :--- | :--- |
| **오늘의 할 일** | 오늘에 해당하는 일정만 모아 보고, 완료를 체크합니다. |
| **반복 일정** | 매일·매주 해야 할 일을 한 번 등록합니다. 완료 기록은 날짜별로 남습니다. |
| **우선순위** | 높음·보통·낮음으로 지정합니다. 미완료 항목 중 중요한 일이 먼저 표시됩니다. |
| **메뉴 막대** | 오늘 목록과 진행 현황을 확인하고, 상위·하위 TODO 완료 체크와 우선순위 변경을 합니다. |
| **통계** | 7일·30일의 완료율, 우선순위별 성과, 이전 기간 비교와 작업별 시간 기록을 확인합니다. |
| **위젯** | 소형·중형 화면으로 남은 일과 진행 현황을 표시합니다. 현재 앱 내 미리보기를 확인할 수 있습니다. |
| **로컬 저장** | 할 일과 완료 기록을 이 Mac에 보관하고 재실행 후에도 유지합니다. |
| **기간 작업·하위 TODO** | 시작일과 종료일을 정하고, 작업을 하위 항목으로 나눠 체크합니다. |

### 한 번 할 일도, 꾸준히 할 일도

**할 일 추가** 또는 **⌘N**으로 제목, 메모, 우선순위와 일정을 등록합니다.

| 반복 방식 | 표시되는 날 |
| :--- | :--- |
| **하루만** | 선택한 날짜에 한 번 |
| **매일** | 시작일부터 매일 |
| **기간 작업** | 시작일부터 종료일까지, 두 날짜 포함 |
| **매주** | 시작일과 같은 요일마다 |

<p align="center">
  <img src="docs/images/task-registration.png" alt="할 일 등록 — 제목, 메모, 우선순위, 반복 방식과 날짜 설정" width="520">
</p>

목록 오른쪽 **연필 버튼**으로 제목·메모·우선순위·반복 방식·날짜를 수정할 수 있습니다. **저장**을 눌러 적용하거나 **취소**로 되돌아갑니다. 완료 기록은 유지되며, 날짜나 반복 방식을 바꾸면 과거 계획 수도 새 일정에 따라 다시 계산됩니다.

**기간 작업**은 한 번 완료하면 종료일까지 완료 상태를 유지합니다. 기간이 지나면 오늘 목록에서 빠지고 **전체**에서 확인할 수 있습니다. 통계에는 완료한 날짜에만 완료 실적을 기록하며, 완료 전에는 기간 내 각 날짜를 계획에 포함합니다.

날짜 카드를 누르면 월별 달력이 열립니다. 화살표로 월을 이동하고 날짜를 선택하거나 **오늘로 선택**을 누르세요. 기간 작업의 시작일·종료일은 나란히 표시됩니다.

등록·수정 창의 **하위 TODO 추가**로 작업을 나눠보세요. 하위 제목 수정·삭제와 앱·메뉴 막대에서 개별 체크를 지원합니다. 상위 작업은 직접 완료 처리하며, 통계와 위젯은 상위 작업 기준입니다. 기간 작업의 하위 체크는 유지되고, 반복 일정의 하위 체크는 날짜별로 관리합니다.

‘평일마다’는 새 일정 선택에서 제거했습니다. 기존 평일 일정은 보존하며 수정 저장 시 선택한 새 방식으로 전환됩니다.

반복 일정을 오늘 완료해도 다음 반복일에는 다시 미완료로 표시됩니다. 우선순위 변경과 삭제는 반복 일정 전체에 적용됩니다.

### 언제 시작하고 끝냈는지

앱이나 메뉴 막대에서 **시작**을 누르면 실제 시작 시각이 기록됩니다. 완료를 체크하면 실제 완료 시각과 소요 시간이 표시됩니다. 예약한 시작일·종료일과 별개이며, 소요 시간은 휴식을 포함한 경과 시간입니다. 반복 작업은 오전 6시 기준 작업일별로, 기간 작업은 여러 날에 걸쳐 이어서 기록합니다.

시작 없이 완료하면 완료 시각만 기록합니다. 완료를 취소하면 완료 시각을 지우고 시작 시각은 유지합니다. 이전 버전의 완료 날짜는 보존하되 알 수 없는 시각을 추정하지 않습니다.

### 체크가 쌓이면 기록이 됩니다

**보기 → 통계**에서 오늘의 달성률과 최근 **7일 / 30일**의 흐름을 확인하세요. 날짜별 완료·미완료 차트, 완료한 날 수, 이전 동일 기간 대비 완료 수, 우선순위별 성과를 제공합니다. 작업별 시간 기록에서 실제 시작·완료 시각과 소요 시간을 확인하고 **완료만**으로 필터링할 수 있습니다. 평균 소요는 시작·완료 시각이 모두 있는 작업만 집계합니다. 삭제한 일정의 과거 기록도 보존합니다.

### 데스크톱에서도 가깝게

소형 위젯은 미완료 항목을 최대 **2개**, 중형은 최대 **3개** 보여줍니다. 높은 우선순위의 일이 먼저 표시되고, 위젯을 누르면 앱이 열립니다. 완료 체크는 앱이나 메뉴 막대에서 할 수 있습니다.

## 시작하기

**macOS 14 이상 · Xcode 16 이상(Swift 6)**이 필요합니다. 로컬 빌드는 Xcode 26.5에서 확인했으며, 외부 패키지나 프로젝트 생성 도구는 필요하지 않습니다.

```sh
git clone https://github.com/cg-1119/P2J.git
cd P2J
open P2J.xcodeproj
```

1. Xcode에서 **P2J** 스킴과 **My Mac**을 선택합니다.
2. [개발 가이드](docs/DEVELOPMENT.md#개발-서명)에 따라 개발 서명을 설정합니다.
3. **⌘R**로 실행합니다.

앱 창을 닫아도 메뉴 막대에서 계속 사용할 수 있습니다. 앱을 완전히 닫으려면 **종료**를 선택하세요.

현재 기기 간 동기화와 알림은 지원하지 않습니다.

## 개발 문서

앱은 **SwiftUI**, 메뉴 막대는 **MenuBarExtra**, 위젯은 **WidgetKit**으로 만듭니다. 일정·완료·통계 로직은 공유 모듈로 관리하며 Swift Package로 테스트합니다.

- [개발 가이드](docs/DEVELOPMENT.md) — 프로젝트 구조, 빌드, 서명, 테스트
- [위젯 가이드](docs/WIDGETS.md) — App Group 연결과 검증 방법
- [스크린샷 관리](docs/SCREENSHOTS.md) — 이미지 출처와 갱신 기준

라이선스는 아직 정하지 않았으며, 배포 전에 이용·재배포 조건을 명시할 예정입니다.
