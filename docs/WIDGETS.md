# 위젯 개발 및 설치

[← README](../README.md)

## 현재 구현

소형·중형 위젯이 오늘 남은 일과 완료 현황을 표시합니다. 소형은 미완료 항목 최대 2개, 중형은 최대 3개를 우선순위가 높은 순서로 표시합니다. 같은 우선순위 안에서는 등록 순서를 따르며, 높은 항목에는 깃발 표시가 붙습니다. 위젯을 누르면 `p2j://today`로 앱을 엽니다. 위젯 안에서 직접 완료 체크하는 기능은 아직 없습니다.

앱의 **위젯 보기**에서 같은 화면 코드로 현재 데이터를 미리 볼 수 있습니다. 이 화면은 WidgetKit 실행 환경이 아니므로 데스크톱 위젯 등록 검증을 대체하지 않습니다.

## 공유 방식

- 원본: 기존 앱의 `Application Support/TODOFirst/tasks.json`
- 위젯 복사본: App Group 컨테이너의 `widget-snapshot.json`
- 앱만 복사본을 쓰고 위젯은 읽기만 합니다. 보관된 항목과 메모는 전달하지 않습니다.
- 앱 시작·다시 불러오기·등록·삭제·완료 체크 성공 후 복사본을 원자적으로 저장하고 WidgetKit에 갱신을 요청합니다.
- 공유에 실패해도 원본의 저장 성공을 취소하지 않습니다. 미리보기 창에서 연결 안내와 다시 보내기 버튼을 제공합니다.
- 별도 원본 이전이 없어 기존 데이터 마이그레이션은 필요하지 않습니다.

위젯은 현재 시점과 이후 7일의 자정 엔트리를 준비합니다. 매일 반복 일정의 완료 상태는 다음 날 다시 계산합니다. 15분 뒤 새 타임라인을 요청하지만 실제 갱신 간격은 macOS가 결정하므로 정확한 주기를 보장하지 않습니다. [Apple의 위젯 갱신 설명](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date/)

## 개발 서명 설정

1. `Configuration/Local.xcconfig.example`을 `Local.xcconfig`로 복사합니다.
2. `DEVELOPMENT_TEAM`에 본인의 10자리 Team ID를 입력합니다.
3. Xcode 계정에 해당 팀의 유효한 개발 서명 인증서가 있는지 확인합니다.
4. 앱과 위젯이 같은 `P2J_APP_GROUP` 값을 사용하도록 설정합니다. 기본값은 `$(DEVELOPMENT_TEAM).com.cg1119.p2j`입니다.
5. `P2J.xcodeproj`의 `P2J` 스킴으로 앱을 빌드·실행합니다.

두 타깃의 entitlements에 같은 App Group이 들어 있으며, Info.plist의 `P2JAppGroup`과 `P2JDeveloperTeam`에도 빌드 설정이 반영됩니다. 개인 서명 설정은 Git에서 제외됩니다.

macOS에서 사용하는 `<Team ID>.<그룹 이름>` 형식은 앱 서명의 개발 팀과 접두어가 일치해야 합니다. 이 방식의 App Group은 별도 프로비저닝 프로파일이 필요하지 않습니다. [Apple의 App Group 컨테이너 설명](https://developer.apple.com/documentation/xcode/accessing-app-group-containers)

서명을 끈 빌드는 코드와 패키징 검증 용도입니다. 가짜 Team ID를 넣거나 그룹 폴더를 수동 생성해 실제 연결 검증을 대신하지 마세요.

## 데스크톱에 추가

1. 서명된 P2J 앱을 실행하고 **위젯 보기**에서 데이터 연결 상태를 확인합니다.
2. 데스크톱을 보조 클릭하고 **위젯 편집**을 선택합니다.
3. **P2J**를 검색해 소형 또는 중형을 추가합니다.
4. 위젯을 눌렀을 때 P2J 앱이 열리는지 확인합니다.
5. 앱에서 완료 체크·취소 후 위젯의 남은 일과 완료 수가 바뀌는지 확인합니다.
6. 반복 일정의 다음 날 표시도 확인합니다.

위젯이 나타나지 않으면 앱·확장의 개발 팀, App Group과 번들 식별자, 앱 실행 여부를 확인하세요. 데이터가 비어 있으면 앱의 **위젯 데이터 다시 보내기**를 사용합니다.

## 검증 범위

- 자동 테스트: 복사본 저장·읽기, 표시 계산, 날짜 전환과 서머타임, 오류 처리
- Xcode 빌드: 앱·위젯 확장 컴파일 및 포함
- 실제 앱: 소형·중형 미리보기, 미완료/모두 완료 상태, 서명 미설정 안내
- 미검증: 개발 서명된 App Group 접근, macOS 데스크톱 등록, 실제 WidgetKit 갱신 및 위젯 클릭

현재 작업 환경에 개발 서명 인증서가 없어 마지막 항목은 별도 서명 환경에서 확인해야 합니다.
