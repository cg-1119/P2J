앱 화면은 실제 실행 결과입니다. 캡처 당시 창에 표시된 시스템 UI도 그대로 포함되어 있습니다. 위젯은 실제 등록·표시 검증 후 캡처를 추가합니다.

## 갱신 기준

1. 문서에 소개할 기능이 구현된 커밋을 빌드합니다.
2. 캡처용 데이터가 필요하면 개인 정보가 없는 예시 데이터만 입력합니다.
3. 앱 창 또는 해당 UI만 캡처해 바탕화면과 다른 앱의 정보가 섞이지 않도록 합니다.
4. 읽을 수 있는 해상도의 PNG로 저장하고 README에 상대 경로로 연결합니다.
5. 캡처 날짜, 대상 커밋과 구현 상태를 이 문서에 기록합니다.
6. GitHub에서 이미지 표시와 설명을 확인하고 관련 문서 커밋에 포함합니다.

캡처용 예시 항목 3개를 직접 등록했으며 앱의 자동 생성 데이터는 아닙니다. 향후 추가할 화면은 우선순위 변경, 메뉴 막대 빠른 보기, 소형·중형 위젯입니다. 예상도나 목업을 추가한다면 실제 실행 화면과 구분해 표기합니다.
